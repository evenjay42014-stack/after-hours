## What the desk does

- Night board of missed calls / forms / SMS / reviews
- Owner-voice SMS, email, and review drafts
- Safety-first copy (don't keep resetting the breaker; shut the heater down)
- Status: new → drafted → sent → booked
- Monday report
- Data stays in the browser (`localStorage`)

It does **not** answer the live phone, invent a price, or dispatch a truck.
